Read a JSON schema of KEY to string|number|bool and validate process.env. Exit 1 when keys are missing or the wrong type.

Package version: **1.00** (`1.0.0`).

## Install

```bash
git clone https://github.com/theworker02/envshape.git
cd envshape
npm install -g .
```

## Usage

```bash
envshape schema.json
```
