# Changelog

All notable changes to **envshape** are documented here.

## 1.00 — 2026-08-23

- Expanded CLI: subcommands and flags people actually use, `--json` / human output, stdin or file paths where it makes sense, `-h`/`--help` and `-V`/`--version`, and non-zero exits on errors.
- Initial public release (**1.00** / `1.0.0`).
- CLI with `--help` and `--version`.
- Product documentation and GitHub Pages site on `main` / `/docs`.
- Validate process.env against a tiny JSON type schema.
